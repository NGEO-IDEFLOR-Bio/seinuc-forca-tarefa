# Sprint Kanban Template - Conteúdo

## Arquivos Incluídos

```
sprint-kanban-template/
├── api/
│   └── save-tasks.js       Serverless function (GitHub API)
├── .gitignore              Configuração Git
├── kanban.html             Interface Kanban completa
├── gantt.html              Visualização Gantt
├── package.json            Scripts NPM
├── tasks.json              Dados exemplo (personalize!)
├── vercel.json             Configuração Vercel
├── README.md               Documentação completa
└── SETUP_GUIDE.md          Guia rápido de setup
```

## Próximos Passos

1. Leia `SETUP_GUIDE.md` para instruções passo a passo
2. Customize `tasks.json` com suas tarefas
3. Deploy no Vercel (5 minutos)
4. Configure GitHub token
5. Pronto para usar!
